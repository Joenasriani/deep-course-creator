# IntelliCourse Creator

IntelliCourse Creator is an interactive course-building prototype that turns a topic into a structured learning experience.

## What it does

- Builds a syllabus and lesson sequence
- Produces detailed tutorial material
- Adds quizzes and practice activities
- Includes educational games and reinforcement exercises
- Organizes the result into a navigable course experience

## Status

Prototype. Generated course material should be reviewed for factual accuracy, instructional quality, and current platform information before publication.

## Run locally

```bash
npm install
npm run dev
```

Some generation features require runtime credentials configured outside source control.
